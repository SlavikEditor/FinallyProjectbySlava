# FinallyProjectbySlava

Идея проекта:
Climate Watcher — трекер глобального потепления

Программа автоматически собирает и анализирует статистику по глобальному потеплению из открытых источников и показывает, как меняется климат со временем.

📊 Что именно собирает программа

(всё — в виде чисел и статистики, без политики)

🌡️ Средняя глобальная температура по годам

❄️ Площадь арктических льдов

🌊 Уровень мирового океана

🌫️ Концентрация CO₂ в атмосфере

🔥 Количество экстремальных погодных событий

🛠️ Как это будет реализованно?

1️) Сбор данных

Программа:

запрашивает страницы с открытой климатической статистикой

парсит таблицы и значения

сохраняет данные локально (CSV)

Используется:

requests

BeautifulSoup

2️) Хранение статистики

данные по годам

обновление при каждом запуске

история сохраняется, а не перезаписывается (CSV)

3️) Анализ данных

Программа считает:

рост температуры за N лет.

среднюю скорость изменений

сравнение периодов (например, 1980–2000 vs 2000–2025)

4️)Визуализация

график роста температуры

график уменьшения льдов

сравнение нескольких показателей

Библиотеки:

matplotlib

pandas

5️⃣ Авто-отчёт

Программа сама формирует текст, например:

«За последние 10 лет средняя температура выросла на X градусов,
а площадь льдов сократилась на Y%.»
