# FinallyProjectbySlava

# О ПРОЕКТЕ #

Кратко: этот проект анализирует и визуализирует изменения концентрации CO2 и глобальной температуры во времени на основе наборов данных. Цель - показать взаимосвязь между ростом выбросов CO2 и изменением глобальной температуры, а также сгенерировать графики.

* СУТЬ ПРОЕКТА: *
- Анализ: очистка и агрегация данных, расчёт трендов, корреляций и простых статистик.
- Визуализация: временные ряды, скаттеры с линиями тренда, тепловые карты или прочие информативные графики.
- Вывод: экспорт графиков и таблиц для дальнейшего чтения или включения в отчёт.

* ФАЙЛЫ: *
- main.py - основной скрипт, программа, обработки данных и построения графиков.

* КАК ЗАПУСТИТЬ? *

Запустите главный скрипт:

python main.py

* ДОСТУПНЫЕ КОМАНДЫ: *
/sample — Создать пример данных
/update — Обновить данные из интернета
/analyze — Анализировать тренд
/plot — Построить графики
/report — Показать отчет
/all — Всё сразу (создать + анализ + графики + отчет)
/help — Справка

* О ТОМ, ЧТО В РЕЗУЛЬТАТАХ: *
- Смотрите временные ряды CO2 и температуры: устойчивый рост CO2 часто коррелирует с ростом среднегодовой температуры.
- Обратите внимание на лаги и сезонные эффекты — корреляция не всегда означает немедленную причинно-следственную связь.
- Результаты визуализации лучше интерпретировать совместно с кратким текcтовым отчётом (можем добавить шаблон и автоматическую генерацию отчёта).
